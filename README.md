# 星际茶餐厅

English name: **Interstellar Cha Chaan Teng**

RimWorld 1.7 模组。生产食品级聚丙烯塑料颗粒和片材，将加工食品封装为包装生存食品，并提供塑料互转、工程塑料零部件配方。依赖 Harmony。

## 可包装食品的确定规则

每次游戏定义加载完成后，DLL 从所有已加载的 `ThingDef` 重建三种包装配方的原料范围，不按模组名称维护白名单。切换语言和开发者定义重载也会重建。

普通食品须同时满足：

1. 是可食用物品，食物类型允许人类食用。
2. 游戏解析、继承及补丁处理后的营养值为有限正数。不设最低营养门槛。
3. 不是尸体、生食原料类别 `FoodRaw` 及其子类，也不是药物或 `Drugs` 类别。
4. 食物类型包含 `Meal` 或 `Processed`，或归入 `FoodMeals` 类别及其子类。

因此餐食、干肉饼、婴儿食物、巧克力、日光果果汁及符合规则的模组加工食品都会自动纳入。`NeverForNutrition` 只影响自动进食偏好，不会阻止包装。仅仅“有生产配方”不视为加工食品，例如人造生肉仍然排除。食品自己的营养数值照单全收，不根据市场价格、心情、餐食品级或来源配方重新平衡。

包装生存食品 `MealSurvivalPack` 默认不可再次包装，可通过默认关闭的彩蛋选项开放，仍只按其实际营养值计量。三种配方保持原有投入与产出：

| 产出包装生存食品 | 塑料片 | 食品营养值 |
|---|---:|---:|
| 5 份 | 5 | 4.5 |
| 9 份 | 9 | 8 |
| 13 份 | 12 | 12 |

**包进去众生平等。** 简单、精致、奢侈只按实际营养值计量，可混用；塑料仍按个数计量。不可拆分的食品按原版取整取料，因此一批只用 C 口粮时分别需要 3、4、6 份，多余营养不退回。原有损耗、成本、产量、工时及其他配方数值均未改动。

## 包材与食材记录

塑料片是固定耗材，不出现在订单右侧的可选食品菜单，不用勾选，仍须备足并消耗原定的 5 / 9 / 12 片。订单的需求说明仍显示包材用量；已有订单也不需要重建或修改塑料勾选。

新制作的包装生存食品仅记录食品，不把食品级塑料片列作食材。例如只使用 C 口粮时，显示「原料：C口粮」。仅为 `MealSurvivalPack` 添加一个无状态组件，不替换原版食材组件，也不新增全局 Harmony 补丁；其他食品保留原版行为。

不扫描存量、不在读档时清理：旧成品原有记录保持不变。若按原版规则允许堆叠，合并双方会在原版食材合并前排除塑料，避免重新污染新堆，也避免塑料占用三种食材的记录上限。部分合并的剩余旧堆也会在此次操作中清理；原版即使转移数量为零仍合并食材记录，因此通过兼容检查的满堆尝试也会清理双方。原版不兼容的堆叠仍拒绝，旧堆仅拆分则不清理。不强制新旧食品堆叠。

## 模组设置

在原生模组选项中打开「星际茶餐厅」：

* **可包装的食品包括营养膏**：默认开启，控制原版营养膏 `MealNutrientPaste`。
* **可包装的食品包括粗饲料**：默认关闭，控制食物类型带 `Kibble` 标记的食品，包括同类模组饲料。
* **包装生存食品可以再包装**：默认关闭的彩蛋选项。开启后允许以包装生存食品作为三种包装配方的原料；中文悬停提示为「……真的要开启吗w」。

勾选立即更新配方，关闭原生设置窗口时由游戏保存。新订单取得当前默认原料；已有订单保留玩家自己的选择，新开放食品须在订单原料筛选中勾选或新建订单。关闭某类食品会立即通过配方固定筛选限制已有订单，不覆盖其个人筛选。

## 失能机关 C 口粮

安装 The Dead Man's Switch / The Dead Man's Switch II 且其定义 `DMS_CombatRation` 存在时，自动作为特例纳入，仅在本模组包装配方中按 **每份 2.0 营养值**计量。

不修改口粮自身的营养属性、直接食用行为或其他配方。不要求安装失能机关，不引用其程序集。包装不会继承原食品的休息恢复、药物或其他特殊进食效果。

## 中英本地化

`Languages/ChineseSimplified` 与 `Languages/English` 分别存放静态单语名称、模组说明、设置、全部物品及 14 个配方的文本。基础 Def 和 About 采用英文回退。启用后模组列表与设置标题随游戏语言显示「星际茶餐厅」或「Interstellar Cha Chaan Teng」，不再合写。

原版没有 About 名称的语言注入入口，因此 DLL 仅对本模组的元数据 getter 使用 Harmony。启动语言尚未加载、模组未启用或缺少译文时回退 About 英文；getter 不加载语言、不调用翻译器，避免启动期间的语言递归。

## 构建

塑料贴图的程序化生成入口、隔离预览命令与历史设计材料见 [Tools/Plastic](Tools/Plastic/README.md)。

本机 RimWorld 1.7.4995 rev309 使用 .NET 10 / Waylith，程序集针对 `net10.0` 构建：

```sh
dotnet build Source/AyameICCT/AyameICCT.csproj -c Release
```

`GameRoot` 和 `HarmonyPath` 可通过 MSBuild 属性覆盖，输出为 `Assemblies/AyameICCT.dll`。游戏安装目录仅用作引用，构建不会自动部署。不要把 Harmony DLL 复制进本模组。
