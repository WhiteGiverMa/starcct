# 星际茶餐厅 · 商号与部队番号生成器

给这个 RimWorld 模组的派系与部队起名字的预览脚本。纯 Bun + TypeScript，不读游戏文件、不写盘；跑一次只在终端打印名字。风格是「广式茶餐厅的店号」混一点科幻味，前缀、后缀、部门、番号单位都可以直接在 `namegen.ts` 顶部的词池里增删。

## 运行

需要 Bun 1.3+。从仓库根目录：

```powershell
bun Tools/Namegen/namegen.ts --help
bun Tools/Namegen/namegen.ts --faction 星际茶餐厅 --count 12
bun Tools/Namegen/namegen.ts --faction 星际茶餐厅 --digits chinese --seed 20261105
```

| 参数 | 说明 |
|---|---|
| `--faction <名字>` | 派系名，用来拼部队番号；不传则只生成商号 |
| `--count <数量>` | 每类生成数量，默认 8，范围 1..200 |
| `--seed <种子>` | 固定随机种子，复现同一批名字 |
| `--digits <风格>` | 番号写法：`arabic`（默认，第37）或 `chinese`（第三十七） |
| `--restaurant-only` | 只生成茶餐厅商号 |
| `--military-only` | 只生成部队番号 |
| `-h`, `--help` | 显示帮助 |

## 名字怎么拼

- **商号** = 两字或三字前缀 + 后缀。两字前缀是广式成词字号（顺景、满盈、鸿福、静好……），三字前缀是老字号、地名与叠字（金满堂、深水埗、天天旺……），另有少量科幻味的词（星港、轨道、深空、废土、锈港……）。后缀覆盖冰室、餐室、茶餐厅、茶楼、食肆、酒店、驿站，以及星际茶楼、星港食堂、废土茶寮这类变体。
- **部队番号** = 派系名 +（可选机关）+（可选修饰）+ 第 N + 单位。机关有国防部、武装部、参谋本部、联合指挥部等；修饰有近卫、先锋、铁血、功勋等；单位按师、旅、团、军分级，番号上限随级别走（师 1..199、旅 1..299、团 1..499、军/舰队 1..99）。
- 前缀与后缀共用同一个双字片段时会重抽，避免「星港星港食堂」这种叠词；同名结果也会去重。

## 和游戏的关系

这是离线预览脚本，不读取存档，也不改 Def。要把同一套词池搬进游戏内运行（例如按 `Faction.Name` 生成番号），需要在 `Source/AyameICCT` 里加一个不依赖 RimWorld 类型的 C# 生成器类；目前还没加。
